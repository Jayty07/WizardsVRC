Put the UdonProduct assets for the VRChat store here (VRChat SDK > UdonProducts Manager, or Assets > Create > VRChat >
UdonProduct and paste the product ID). The scene builder reads this folder on every rebuild:

  Shards_100, Shards_500, ...   Starshard bundles: the number is how many Starshards each purchase gives.
                                Sell them as Instant listings with quantity purchases on.
  Patron (any name, no number)  A supporter perk: owning it unlocks the Patron title and aura (the first perk by name).
                                Sell perks as Permanent listings.

See "Selling Starshards for real money" in the README.
